# Adaptive page layout — confirmed

Default pages use 4–6 comic panels with speech balloons and captions. The layout engine can enlarge a major event or climax into a hero panel. A single pivotal scene may occupy a full-page splash.

The current pure layout planner selects standard, hero, or splash layout from structured story moments. It does not render images, typeset balloons, or charge credits. Each successfully generated **page** will count as one quota unit regardless of its number of panels; image-generation costs must be validated before subscription launch.

Rendering plan: generate panel art with a stable character reference, assemble at a consistent portrait page resolution, reserve space for readable text, and verify that the resulting page matches the narrative script.
