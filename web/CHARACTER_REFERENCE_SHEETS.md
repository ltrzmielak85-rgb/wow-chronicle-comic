# Character reference sheets — confirmed

Use one approved, reusable visual identity reference sheet per character version. Preserve face, race features, skin, tusks, hairstyle and other stable identifying traits across pages. A character's level, armor, weapons and other evolving equipment are resolved independently using the latest recorded appearance snapshot **at or before the illustrated quest**. Never copy future gear from the reference sheet. If no historical gear record exists, do not invent named equipment.

Implemented: versioned approved reference sheet schema with owner-read RLS, private image path, historical reference prompt assembly, and draft tests. The existing optional screenshot/appearance data remains useful input.

Not yet implemented: reference-sheet image creation, owner approval UI, image-model reference input, upload/download authorization endpoints, worker integration, migrations execution, or test execution.
