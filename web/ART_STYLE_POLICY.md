# Three art styles — confirmed
Players select one of three named presets before approving a comic: Classic Fantasy Comic, Dark Cinematic, or Vibrant Adventure.

The selected style is stored with the generation request and finished comic. A stable character appearance profile and optional screenshot reference take precedence over stylistic embellishments, so the protagonist remains recognizable between pages and across styles.

Implemented: typed preset registry, continuity-aware art direction helper, database migration, draft tests.

Pending: style picker UI, image provider, visual consistency checks, rendering, and test execution. Avoid imitating a living artist's distinctive style or using protected Warcraft art assets without authorization.
